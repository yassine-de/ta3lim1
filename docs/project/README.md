## Arbeitsregeln

1. Entscheidungen werden im Entscheidungslog festgehalten.
2. Neue Anforderungen werden zuerst im Backlog bewertet; sie verändern den MVP nicht automatisch.
3. Ein Arbeitspaket gilt nur als abgeschlossen, wenn seine Abnahmekriterien erfüllt sind.
4. Risiken mit hoher Auswirkung werden wöchentlich geprüft.
5. Inhalte benötigen fachliche und sprachliche Freigabe vor Veröffentlichung.
